# 🌙 Selamat Malam, Chloe

Mini online book dengan background langit malam, musik, dan pesan-pesan malam yang hangat.

## 📁 Struktur File

```
chloe-book/
├── index.html   ← file utama
├── bg.jpg       ← background langit malam
├── music.mp3    ← musik latar
└── README.md
```

## 🚀 Cara Upload ke GitHub Pages

1. **Buat repo baru** di GitHub (contoh: `selamat-malam-chloe`)
2. **Upload semua file** (index.html, bg.jpg, music.mp3, README.md)
3. Pergi ke **Settings → Pages**
4. Di bagian *Source*, pilih **Deploy from a branch**
5. Pilih branch `main`, folder `/ (root)` → klik **Save**
6. Tunggu ~1 menit, lalu akses:
   ```
   https://[username].github.io/selamat-malam-chloe/
   ```
